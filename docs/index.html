4-ary min-heap timer · 对应 esrrhs/heap_timer（仿 Golang 四叉堆定时器）

教学时间：本演示使用抽象时间单位（非真实毫秒）。 Add(delay) 写入 when = now + delay，再 SiftUp； Update(now) 在根节点 when ≤ now 时反复弹出根（换末尾到 0，再 SiftDown）； Del(id) 经 timer_map_ 定位，末尾填洞后先 SiftUp 再 SiftDown。 父子：父 (i−1)/4，子 i×4+1 .. i×4+4。逻辑与 heap_timer.h 一致；真实代码用 steady_clock，且非线程安全。

操作日志

① 插入 / SiftUp

Append 到 heap_[heap_size_]，沿父链 (i−1)/4 上浮，直到 when ≥ 父 when。写入 timer_map_。

② Update / 弹根

根 when ≤ now 时弹出：末尾换到 0，SiftDown 选四子中最小者下沉；从 map 擦除并收集 id。

③ 删除 + Sift

按 id 查 map，i=-1；末尾填洞后对该下标先 SiftUp 再 SiftDown（与 C++ 相同）。

④ 为何四叉

比二叉堆更浅：n 个节点高度约 log₄ n。SiftDown 每次比较最多 4 子，缓存友好，适合大量定时器。
